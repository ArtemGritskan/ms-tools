# Документация к плагину Mining Cluster Tools (v0.3.0)

Плагин `mc-tools` разработан для сайта **Mining Cluster** и объединяет два независимых интерактивных инструмента:
1. **Калькулятор стоимости размещения** (полная рабочая версия).
2. **Налоговый калькулятор майнера** (актуальная версия под 5-ступенчатую прогрессивную шкалу ФНС 2026 года).

Плагин полностью изолирован, не создает нагрузку на базу данных WordPress, не оставляет мусора при удалении и оптимизирован для бесконфликтной работы нескольких шорткодов на одной странице.

---

## 1. Установка в три клика

1. **Загрузка:** Перейдите в админ-панель WordPress ➔ `Плагины` ➔ `Добавить новый` ➔ `Загрузить плагин`. Выберите очищенный архив `mc-tools.zip` и нажмите `Установить`.
2. **Активация:** Нажмите кнопку `Активировать плагин` в списке установленных плагинов.
3. **Размещение:** Скопируйте и вставьте необходимый шорткод в текстовый редактор или блок "Шорткод" любой страницы сайта.

---

## 2. Настройки шорткодов и параметров

Плагин поддерживает вывод калькуляторов в различных режимах с помощью динамических атрибутов шорткода:

* `[mc_hosting_calc]` — Калькулятор стоимости размещения оборудования. Рассчитывает затраты на хостинг по формуле: `кВт × 730 ч × аптайм × тариф`.
* `[mc_tax_calc]` — Налоговый калькулятор по умолчанию (с ручным выбором статуса: Физлицо, ИП или Юрлицо).
* `[mc_tax_calc status="fiz"]` — Налоговый калькулятор, жестко зафиксированный для страницы физических лиц (выбор скрыт).
* `[mc_tax_calc status="ip"]` — Налоговый калькулятор, зафиксированный для страницы ИП (расчет НДФЛ для ИП по ст. 227 НК РФ).
* `[mc_tax_calc status="org"]` — Налоговый калькулятор, зафиксированный для страницы ООО на ОСНО (налог на прибыль 25%).

## 3. Обслуживание плагина: что и как изменять

Вся тарифная, конфигурационная и законодательная логика полностью вынесена из программного кода в изолированные конфигурационные JSON-файлы в папке `config/`. Это позволяет обновлять данные без изменения кода.

### Изменение каталога ASIC и базовых тарифов хостинга:
**Файл:** `config/hosting-config.json`
* Изменение базовой стоимости электричества: отредактируйте строку `"default_tariff": 3.3`.
* Обновление моделей: добавьте новые элементы в массив `"asics"`. Каждый аппарат должен иметь вид: `{"name": "Название модели", "power_w": Потребление в Ваттах}`.

### Изменение порогов прогрессии, ставок и источников ФНС:
**Файл:** `config/tax-rules-2026.json`
* **Настройка 5-ступенчатой шкалы:** Массивы `"mining_scale"` (майнинг) и `"sale_scale"` (продажа) содержат шаги прогрессии. Вы можете изменять лимиты ступеней (`"limit": 2400000`) и ставки (`"rate": 0.13`), новые шаги подтянутся в JS автоматически без жесткого кодирования.
* **Обновление источников:** Поля `"source_stage1"`, `"source_stage2"` и `"link"` содержат прямые ссылки на внутренние страницы `/doc/fns/` и официальные цитаты. Изменения в этих полях мгновенно обновляют раскрывающийся блок «Посмотреть обоснование» на фронтенде.

## 4. Что проверить (Чек-лист для тестирования)

1. **Режим отладки:** В файле `wp-config.php` должно быть включено `define('WP_DEBUG', true);`. При активации и работе плагина файл `wp-content/debug.log` должен оставаться пустым (отсутствие Warning и Notice).
2. **Динамический кэш-бастинг:** Плагин отслеживает время изменения ассетов через функцию `filemtime`. При сохранении `mc-script.js` или `mc-style.css` версия скрипта обновляется автоматически, принудительно пробивая кэш браузеров.
3. **Бесконфликтность с WooCommerce:** Убедитесь, что в системе активирован плагин `WooCommerce`. Внешний вид калькуляторов не ломается за счет строгой изоляции стилей префиксом `.mc-`.
4. **Раздельные налоговые базы:** В налоговом калькуляторе налог на добычу и налог на продажу считаются как две абсолютно независимые базы с нуля. При снятии галочки «Криптовалюта уже реализована» строка курса продажи и налог Второго этапа должны мгновенно скрываться.
5. **Адаптивность:** При сужении экрана до **375 px** (стандарт смартфона) карточки калькуляторов перестраиваются в одну вертикальную колонку без появления горизонтального скролла.
6. **Интеграция кнопок заявок:** Нажатие на кнопки «Заказать» и «Получить консультацию» добавляет к URL-адресу страницы якорь `#popup_request` без перезагрузки (триггер существующей формы сайта).

---

## 5. Как откатить изменения или безопасно удалить плагин

* **Откат настроек:** Если данные в JSON-файлах были отредактированы с синтаксической ошибкой, замените содержимое папки `config/` оригинальными файлами из Git-репозитория.
* **Безопасное удаление:** Деактивируйте и удалите плагин через стандартное меню WordPress. Плагин разработан по принципу «чистой очистки» — в базе данных не остается скрытых опций с префиксом `mc_`, а все файлы плагина полностью удаляются с сервера.
